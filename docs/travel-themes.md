남쪽·서쪽 경계는 포함하고 북쪽·동쪽 경계는 제외한다. 구역은 현재 서로 겹치지 않는다. 등록 구역 밖은 일반 여행이다. 유효한 최신 위치가 구역 밖으로 이동하면 이전 테마를 제거한다.

[Pleos 위치 콜백](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/FusedLocation/location-data-access)의 `LocationData.latitude`, `longitude`, `timestampMillis`를 사용한다. 사용 중인 FusedLocation 1.1.3 바이너리에서도 해당 getter를 확인했다. null·오류·범위 밖 좌표·NaN·무한대·미래 시각·60초 초과 과거 시각은 테마를 제거한다. 중복·역순의 유효 샘플은 최신 위치를 덮어쓰지 않는다. 종료 시 마지막 위치의 유효 기간도 다시 검사한다.

차량 메모리에 좌표나 경로를 보관하지 않고 테마와 시간만 유지한다. 여행 제출에는 `city`, `forest`, `sea` 중 하나만 추가하며 위치가 없으면 필드를 생략한다. 속도 기반 이동 시간 집계는 위치 유무와 독립적이다.

## 검증 범위와 남은 구현

단위 테스트는 여섯 구역 내부·경계·외부, 잘못된 좌표, 미수신, null/오류 이후, 신선도 만료, 중복·역순 샘플을 검사한다. 실제 SDK 필드 연결은 Android 컴파일로 검증한다. **SDK를 통한 에뮬레이터 위치 주입은 아직 미검증이므로 B10 통과 근거로 삼지 않는다.**

서버는 유효 이동 시간이 있는 테마 여행을 받으면 도착 시각의 서울 날짜를 기준으로 계정당 풍경 조각 한 개를 지급한다. 같은 날짜의 여러 차량·테마·재전송은 추가 지급하지 않는다. 위치가 없거나 이동 시간이 0이면 조각을 주지 않는다. 기본 재료 보상과 별도 원장으로 관리한다.

첫 쉼터(q01), 토담의 화단(q02), 새미의 작은 정원(q06) 의뢰에서 각각 도시·숲·바다 조각을 한 개 얻는다. 기존 완료 의뢰도 서버 시작 시 중복 없이 보충한다. 각 조각 한 개로 해당 색 제작법을 영구 해금하며, 해금 후 소유 가구에 자유롭게 색을 입힐 수 있다. 가구 스타일 변경은 소유권·마을 버전을 검사한다. 원래 27종 제작법의 재료 비용과 성장 의뢰는 유지된다.

모바일 여행 탭에서 조각 확인·해금을 하고, 마을의 가구를 길게 선택한 뒤 같은 탭에서 색을 입힌다. 세 색은 도시 살구색·숲 초록색·바다 파란색이며 기존 자체 모델의 재질에 적용한다.
