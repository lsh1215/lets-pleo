# 렛츠 플레오 모바일 앱

Godot 4.7.2 Standard의 Android용 3D 마을 게임이다. 자체 제작한 24종 가구·장식, 3종 건물, 주민 3명의 모델을 렌더링한다. 마을·꾸미기·오늘·여행 탭에서 제작·배치·의뢰·정원·차량 연결을 사용한다. 색과 화면 구성은 [디자인 문서](../DESIGN.md)를 따른다.

프로젝트를 Godot 4.7.2로 열고 `export_presets.cfg`의 Android 프리셋을 사용한다. 같은 버전의 공식 Android export templates, Android SDK, JDK 17이 필요하다. 개발 서버는 호스트의 `127.0.0.1:4187`, Android 에뮬레이터에서는 `10.0.2.2:4187`에 연결한다.

2026-11-15: 공식 Godot 4.7.2 템플릿으로 디버그 APK를 생성하고 프로젝트 전용 모바일 AVD에서 3D 화면, 제작·배치, 차량 연결 코드, 오프라인 배치 초안의 재실행·재동기화를 확인했다. 360×800 및 412×915 크기에서 네 탭의 잘림을 검사하고 세 주민의 가구 사용과 가구 이동·보관 후 행동을 녹화했다. 10회 재실행 p95는 디버그 7.186초, 임시 테스트 키로 서명한 릴리스 12.287초로 모두 5초 목표에 미달한다. 모든 콘텐츠 플레이, Android API 34·35, 장시간 내구성 검증은 남아 있다. [최신 화면](../verification/20261115/mobile-floral-412-home.png)과 [성공 기준 현황](../docs/acceptance-status-20261115.md)을 참고한다.

제작 카드에는 게임 안에서 쓰는 모델을 렌더링한 27종 썸네일을 표시한다. 목록을 저장하므로 오프라인 재실행에도 미리보기를 볼 수 있다. 전면 실행 중 2초 간격으로 상태를 확인하고, 변경이 없으면 열린 패널을 다시 만들지 않는다. 재연결 시 누락된 목록을 별도로 다시 조회한다.

2026-11-15 GPU 검증: 전용 API 36 AVD, 412×915, 4 vCPU·2,560MB, Apple M2 Pro host GPU에서 주민 3명·배치물 100개를 600초 측정했다. p95 18.128ms로 프레임 기준을 통과했다. [결과](../verification/20261115/mobile-perf-host-result.json). 시작·실제 탭 응답 10회의 p95는 7.357초로 여전히 5초 기준에 미달하며, 목록 캐시 수정 후 최종 재측정은 남아 있다.
